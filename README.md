
# Keypad block

Adds a block that interacts like keypad, allows the user to input password upto 32 characters of length which then can power blocks/redstone and auto resets after 5 seconds.

- Requires Fabric API

![Shows the crafting combination for the keypad](https://github.com/MerryDreambound/Keypad/blob/main/docs/images/crafting.jpg)
